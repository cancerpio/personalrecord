# 設計：選動作時帶入上次的組次數

日期：2026-08-22

## 目標

在 Record 頁選定訓練動作後，自動把該動作「上次的最後一組」的重量與次數帶入表單，
使用者只需微調或直接送出，減少每一組都要重打數字的負擔。

## 背景

`submitLog()` 送出後**不清空表單**（既有行為）。因此同一動作連續記錄多組時，
數字本來就留在欄位裡，連按 Save 即可。本功能的實際價值在兩個既有流程未覆蓋的情境：

- 在同一次訓練中**切換動作**。
- **隔天重新打開 App**、表單為空時的第一筆。

## 決策

以下三項為 brainstorming 期間逐一確認的選擇，記錄結論與被淘汰的選項。

### 1. 帶出哪一筆：最後一組（含今天）

「最後一組」＝該動作全部紀錄中，依時間排序的最後一筆，**包含當日已記錄的組**。

淘汰的選項：
- 「最重一組」——組間記錄時會一直帶同一個數字，且與遞增課表的實際節奏不符。
- 「上一個訓練日的某一組」——排除當日會讓組間記錄失去接續性。

取「最後一組」而非「最重一組」是刻意的：使用者在組間記錄時，
上一組的數字才是下一組的合理起點。

### 2. 呈現方式：直接填入輸入框

選完動作即把值寫進 `form.weight` / `form.reps`，使用者可直接覆寫或直接送出。

淘汰的選項：只顯示「上次：105kg × 5」提示而不填、提示加一鍵套用、以及填入但用淡色標示。
這些都能降低誤存風險，但都增加互動成本或需要額外 UI 元件；
本功能的目的就是減少按鍵次數，故採最直接的做法。

### 3. 覆寫規則：換動作就覆寫；該動作無紀錄則清空

欄位永遠反映「目前所選動作的上次紀錄」，狀態一致，不會殘留別的動作的數字。

淘汰的選項：
- 「無紀錄則保留原值」——欄位意義變模糊（不知道數字屬於哪個動作）。
- 「只填空白欄位」——因為送出後欄位不清空，實際上幾乎永遠不會觸發。

## 行為規格

- 僅在 `form.exercise` **改變**時觸發。改日期、送出存檔都不觸發，
  既有的「存檔後欄位保留、可連續送出多組」行為不變。
- 不使用 `immediate`：初次載入時 `form.exercise` 為空字串，不應清空任何欄位。
- 動作名稱為空字串時不帶入、不清空既有值以外的處理（getter 直接回 `null`）。

### 「最後一組」的判定順序

1. 先比 `date`（`YYYY-MM-DD` 補零，字典序即時間序）。
2. 同日再比 `createdAt`。
3. 任一方缺 `createdAt` 時，退回陣列原順序（後加入者視為較新）。

`createdAt` 一律經 `new Date(x).getTime()` 正規化。這是必要的：
local 模式存的是 `Date.now()` 數字（`LocalService.js`），
後端存的是 ISO 字串（`backend/src/repositories/types.ts`），兩種型別都要能排序。
早期資料可能完全沒有此欄位，故需要第 3 層 fallback。

## 已知取捨

**動作名稱採精確字串比對**，不做 trim 或大小寫正規化。
`squat` 帶不出 `Squat` 的歷史紀錄。

正規化牽涉到既有資料要不要一併收斂，且「動作變化通知」功能
（`todo_feature_202608.md` 項目 #2）同樣需要判定「同一個動作」，
在該功能一次處理比較乾淨，此處先不動。

## 改動範圍（3 檔）

### 1. `src/stores/sessionStore.js`

- 新增模組層級 helper `toTimestamp(value)`：正規化 `createdAt`，無法解析時回 `null`。
- 新增 getter `getLastSetForExercise(exerciseName)`：
  回傳 `{ weight, reps }`，該動作無紀錄或名稱為空時回 `null`。
  單次走訪 `state.sessions`，依上述三層規則挑出最後一組。

### 2. `src/views/RecordView.vue`

- `watch(() => form.exercise, ...)`：帶入或清空 `form.weight` / `form.reps`。
- 順帶把檔案中段零散的 `import { watch } from 'vue'` 併回頂部 import。

### 3. `src/stores/sessionStore.test.js`

新增 9 個測試（test-first）：跨日取最新、同日取最後一組（明確驗證**非**最重）、
動作間互不干擾、無紀錄／空陣列／空動作名回 `null`、
`createdAt` 為 ISO 字串、缺 `createdAt`、同日混合有無 `createdAt` 不拋錯。

RecordView 的 watch 為三行 glue code，不另外寫元件測試。
